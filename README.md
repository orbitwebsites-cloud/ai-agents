# 24 Real AI Agents for Claude

Every agent from my *100 Agents · 100 Days* build, packaged as Claude skills. No standalone scripts: you install them and Claude uses them with your own connectors (Gmail, Notion, Stripe, GitHub...). I've made videos on these agents; the table shows which have one so far.

## Install (Claude Code)
```
/plugin marketplace add orbitwebsites-cloud/ai-agents
/plugin install ai-agents@ai-agents
```

Then just ask: *"run meeting ops on my last call"* or *"draft replies to my priority emails"*.

**Claude.ai / Claude desktop:** zip any folder in `skills/` and upload it under Settings > Capabilities > Skills.
