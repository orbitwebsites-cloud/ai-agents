# Weekly Review

**What it does:** Every Friday it queries Linear, GitHub and Notion for what shipped and what slipped, then writes a grounded review doc from the real activity.

**Why it matters:** Friday 5pm you get a factual snapshot of the week — wins, slips, and what Monday looks like.

**Trigger:** Friday 5pm
**Connectors it uses:** Linear, GitHub, Notion

## Steps

1. Check which of these connectors are available in this session: Linear, GitHub, Notion. If one the task needs is missing, say which one and ask the user to connect it or paste the data instead. Never pretend you fetched something.
2. Gather the input from the connectors (or from what the user pasted).
3. Do the job described above. Work only from real data: no invented names, numbers, dates or links.
4. Show the result as a short, scannable summary the user can act on in under a minute, and list anything you couldn't decide.
5. Before anything that leaves the machine (sending an email, posting, creating an invoice, charging money, commenting publicly), show the exact draft and wait for the user's yes. Drafts are fine without asking.
