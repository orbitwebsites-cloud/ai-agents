# Document Studio

**What it does:** Pulls real project data from CRM/Notion and your past winning docs as templates to generate proposals, SOWs and agreements, then files them to Drive and sends where relevant.

**Why it matters:** Generate a client-ready proposal grounded in real project data in minutes.

**Trigger:** On demand + CRM events
**Connectors it uses:** CRM, Notion, Drive

## Steps

1. Check which of these connectors are available in this session: CRM, Notion, Drive. If one the task needs is missing, say which one and ask the user to connect it or paste the data instead. Never pretend you fetched something.
2. Gather the input from the connectors (or from what the user pasted).
3. Do the job described above. Work only from real data: no invented names, numbers, dates or links.
4. Show the result as a short, scannable summary the user can act on in under a minute, and list anything you couldn't decide.
5. Before anything that leaves the machine (sending an email, posting, creating an invoice, charging money, commenting publicly), show the exact draft and wait for the user's yes. Drafts are fine without asking.
