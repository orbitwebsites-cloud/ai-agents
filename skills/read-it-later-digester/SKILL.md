# Read-It-Later Digester

**What it does:** Processes your Pocket/Readwise saves and podcast RSS feeds, summarizes each, extracts standout quotes, and files structured notes to Notion while reordering your queue by your current goals.

**Why it matters:** Everything you saved but never read comes back as summarized, searchable notes.

**Trigger:** On save + daily
**Connectors it uses:** Pocket/Readwise, RSS, Notion

## Steps

1. Check which of these connectors are available in this session: Pocket/Readwise, RSS, Notion. If one the task needs is missing, say which one and ask the user to connect it or paste the data instead. Never pretend you fetched something.
2. Gather the input from the connectors (or from what the user pasted).
3. Do the job described above. Work only from real data: no invented names, numbers, dates or links.
4. Show the result as a short, scannable summary the user can act on in under a minute, and list anything you couldn't decide.
5. Before anything that leaves the machine (sending an email, posting, creating an invoice, charging money, commenting publicly), show the exact draft and wait for the user's yes. Drafts are fine without asking.
