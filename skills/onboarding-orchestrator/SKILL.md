# Onboarding Orchestrator

**What it does:** On a new hire or contractor it sends the contract via e-sign, provisions tool and GitHub access, creates the onboarding task checklist in Notion, and schedules the kickoff.

**Why it matters:** A new contractor is signed, provisioned, and scheduled without you lifting a finger.

**Trigger:** On new hire/contractor
**Connectors it uses:** HR, Notion, GitHub, e-sign

## Steps

1. Check which of these connectors are available in this session: HR, Notion, GitHub, e-sign. If one the task needs is missing, say which one and ask the user to connect it or paste the data instead. Never pretend you fetched something.
2. Gather the input from the connectors (or from what the user pasted).
3. Do the job described above. Work only from real data: no invented names, numbers, dates or links.
4. Show the result as a short, scannable summary the user can act on in under a minute, and list anything you couldn't decide.
5. Before anything that leaves the machine (sending an email, posting, creating an invoice, charging money, commenting publicly), show the exact draft and wait for the user's yes. Drafts are fine without asking.
