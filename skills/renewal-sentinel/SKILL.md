# Renewal Sentinel

**What it does:** Tracks insurance, business-registration and license renewal dates and alerts you well ahead of each lapse.

**Why it matters:** You're warned 90 days before insurance renews, so coverage never lapses.

**Trigger:** Ahead of each renewal
**Connectors it uses:** Calendar, records

## Steps

1. Check which of these connectors are available in this session: Calendar, records. If one the task needs is missing, say which one and ask the user to connect it or paste the data instead. Never pretend you fetched something.
2. Gather the input from the connectors (or from what the user pasted).
3. Do the job described above. Work only from real data: no invented names, numbers, dates or links.
4. Show the result as a short, scannable summary the user can act on in under a minute, and list anything you couldn't decide.
5. Before anything that leaves the machine (sending an email, posting, creating an invoice, charging money, commenting publicly), show the exact draft and wait for the user's yes. Drafts are fine without asking.
