# Topic Backlog Manager

**What it does:** Continuously pulls new papers from arXiv/HuggingFace and trend signals via web search, scores each against search demand, and maintains a ranked video-idea database in Notion that it re-orders every week.

**Why it matters:** You never wonder what to film next — the top of your Notion backlog is always the best bet.

**Trigger:** Continuous feed + weekly rerank
**Connectors it uses:** arXiv/HF, Web, Notion

## Steps

1. Check which of these connectors are available in this session: arXiv/HF, Web, Notion. If one the task needs is missing, say which one and ask the user to connect it or paste the data instead. Never pretend you fetched something.
2. Gather the input from the connectors (or from what the user pasted).
3. Do the job described above. Work only from real data: no invented names, numbers, dates or links.
4. Show the result as a short, scannable summary the user can act on in under a minute, and list anything you couldn't decide.
5. Before anything that leaves the machine (sending an email, posting, creating an invoice, charging money, commenting publicly), show the exact draft and wait for the user's yes. Drafts are fine without asking.
