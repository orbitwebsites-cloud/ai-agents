# Meeting Prep + Dossier

**What it does:** 60 minutes before an external meeting it reads the Calendar event, pulls the attendee's LinkedIn and recent company news, your Gmail history with them, and any CRM notes into a one-page brief.

**Why it matters:** You walk into every call already knowing who you're meeting and what was last said.

**Trigger:** 60 min before ext. meeting
**Connectors it uses:** Calendar, LinkedIn, Gmail, CRM

## Steps

1. Check which of these connectors are available in this session: Calendar, LinkedIn, Gmail, CRM. If one the task needs is missing, say which one and ask the user to connect it or paste the data instead. Never pretend you fetched something.
2. Gather the input from the connectors (or from what the user pasted).
3. Do the job described above. Work only from real data: no invented names, numbers, dates or links.
4. Show the result as a short, scannable summary the user can act on in under a minute, and list anything you couldn't decide.
5. Before anything that leaves the machine (sending an email, posting, creating an invoice, charging money, commenting publicly), show the exact draft and wait for the user's yes. Drafts are fine without asking.
