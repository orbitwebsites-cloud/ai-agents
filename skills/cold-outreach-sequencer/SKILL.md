# Cold Outreach Sequencer

**What it does:** On a new CRM lead it enriches from LinkedIn/Clearbit, writes a personalized email grounded in their recent activity, sends via the CRM, and runs a 3-step follow-up that stops the instant they reply.

**Why it matters:** Add a lead and a personalized outreach sequence runs itself until they respond.

**Trigger:** On new lead in CRM
**Connectors it uses:** LinkedIn, Clearbit, CRM

## Steps

1. Check which of these connectors are available in this session: LinkedIn, Clearbit, CRM. If one the task needs is missing, say which one and ask the user to connect it or paste the data instead. Never pretend you fetched something.
2. Gather the input from the connectors (or from what the user pasted).
3. Do the job described above. Work only from real data: no invented names, numbers, dates or links.
4. Show the result as a short, scannable summary the user can act on in under a minute, and list anything you couldn't decide.
5. Before anything that leaves the machine (sending an email, posting, creating an invoice, charging money, commenting publicly), show the exact draft and wait for the user's yes. Drafts are fine without asking.
