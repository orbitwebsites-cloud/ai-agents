# Channel Intelligence

**What it does:** Every Monday it pulls retention curves, CTR and traffic-source data through the YouTube Analytics API, identifies what's actually growing, and writes recommendations back into the topic backlog.

**Why it matters:** Monday morning you learn which videos are winning and exactly what to make more of.

**Trigger:** Monday 8am
**Connectors it uses:** YouTube Analytics API

## Steps

1. Check which of these connectors are available in this session: YouTube Analytics API. If one the task needs is missing, say which one and ask the user to connect it or paste the data instead. Never pretend you fetched something.
2. Gather the input from the connectors (or from what the user pasted).
3. Do the job described above. Work only from real data: no invented names, numbers, dates or links.
4. Show the result as a short, scannable summary the user can act on in under a minute, and list anything you couldn't decide.
5. Before anything that leaves the machine (sending an email, posting, creating an invoice, charging money, commenting publicly), show the exact draft and wait for the user's yes. Drafts are fine without asking.
