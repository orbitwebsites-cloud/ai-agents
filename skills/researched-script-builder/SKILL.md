# Researched Script Builder

**What it does:** When a topic is promoted, it gathers primary sources via web + arXiv, extracts cited facts, drafts a retention-structured script, and saves it with a full source list to Notion.

**Why it matters:** Promote a topic in the morning; a sourced, fact-checked script is sitting in Notion by lunch.

**Trigger:** On item promoted to production
**Connectors it uses:** arXiv, Docs, Web, Notion

## Steps

1. Check which of these connectors are available in this session: arXiv, Docs, Web, Notion. If one the task needs is missing, say which one and ask the user to connect it or paste the data instead. Never pretend you fetched something.
2. Gather the input from the connectors (or from what the user pasted).
3. Do the job described above. Work only from real data: no invented names, numbers, dates or links.
4. Show the result as a short, scannable summary the user can act on in under a minute, and list anything you couldn't decide.
5. Before anything that leaves the machine (sending an email, posting, creating an invoice, charging money, commenting publicly), show the exact draft and wait for the user's yes. Drafts are fine without asking.
